# Before submitting

- Run `flutter pub get`.
- Run `dart format lib`.
- Run `flutter analyze` and fix any project-specific warnings.
- Test airplane mode after loading the catalogue once.
- Verify add/edit/delete remain after force-closing and reopening the app.
- Test on phone and tablet widths.
- Capture genuine emulator screenshots and add them to README.
- Build and test a release APK.
